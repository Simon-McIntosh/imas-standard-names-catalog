# AGENTS.md — AI Agent Instructions

## Overview

This is a **data-only repository** containing the IMAS Standard Names catalog.

**Contents:**
- `standard_names/` — YAML catalog files (one per physics domain)
- `catalog.yml` — export metadata and provenance
- `.github/workflows/` — CI automation
- `src/` — Python package for distributing `catalog.db`

## Rules

### Editing

YAML files are generated by [imas-codex](https://github.com/Simon-McIntosh/imas-codex)
via `sn export`. Edit via PR — the `sn import` command detects changes and marks
them as `origin=catalog_edit` so the pipeline preserves human edits.

### What You Can Do

- Update documentation (README, AGENTS.md)
- Modify CI/CD workflows in `.github/workflows/`
- Update `.gitignore` for build artifacts

### What You Cannot Do

- Edit YAML content directly (use imas-codex `sn export` / `sn import`)
- Add Python dependencies beyond `imas-standard-names`
- Create application logic

## CI/CD

| Workflow | Trigger | Action |
|----------|---------|--------|
| `validate.yml` | PR, push to main | Validates YAML syntax and catalog consistency |
| `catalog.yml` | Push to main/tags | Builds versioned docs site via mike → gh-pages |
| `release.yml` | Tag `v*` | Builds `catalog.db`, `standard_names.zip`, Python wheel |

## Git Workflow

```bash
git add standard_names/ catalog.yml
git commit -m "sn: update catalog entries"
git push origin main
```

**Remember**: This is a data repository. All generation tools live in `imas-codex`.
